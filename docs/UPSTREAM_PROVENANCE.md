# Procedencia y permisos de reutilización

Estado: **pendiente de confirmación documental**.

- Proyecto de origen: https://github.com/kritpoka/deepstash-app-clone
- Proyecto derivado de trabajo: https://github.com/misaqui/microlearning-app
- El repositorio de origen fue utilizado como punto de partida de la estructura Flutter.
- En la revisión realizada no se encontró un archivo LICENSE en la raíz del repositorio original.
- **No se ha recibido ni verificado autorización expresa del titular de derechos.** La decisión de avanzar con análisis, pruebas y desarrollo no equivale a una licencia.
- Esta nota no atribuye al equipo de Microlearning Hub la autoría del código anterior ni reclama créditos sobre él.
- Conservar la procedencia y cualquier aviso de derechos existente; revisar también imágenes, marcas y dependencias de terceros.
- Antes de publicar o redistribuir una versión derivada, verificar una licencia aplicable o una autorización escrita que cubra modificación, distribución y, si procede, uso comercial.

Decisión operativa: preparar funcionalidades y pruebas en `develop`; bloquear la distribución pública de código derivado mientras el permiso no esté confirmado.
